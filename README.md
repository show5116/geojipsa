# 거집사 (GeoJipsa)

거상 여러 클라를 챙겨 주는 집사 프로그램입니다.
클라 상태 보기, 여러 클라 한 번에 열기, 사냥 기록, 홈페이지 이벤트 알림, 사통팔달 알림을 한곳에서.

> **게임에 입력을 보내지 않습니다.** 자동 사냥/매크로 기능이 없고, 게임 파일을 고치지 않습니다.
> 하는 일은 창 목록 보기, 게임 통신 듣기 (Npcap, 읽기만), 게임 데이터 파일 읽기, 홈페이지 읽기뿐입니다.

## 할 수 있는 일

| 탭 | 내용 |
|---|---|
| 상태 | 1/2/3클마다 꺼짐 / 대기 / 전투 중, 지난 시간, 포만도. 포만도가 0 이 되면 알림. '앞으로' 버튼과 단축키로 그 클라 창을 맨 앞으로 |
| 클라 실행 | 클라마다 계정 (본/부) 을 저장해 두고 버튼 하나로 로그인 + 실행. 실행 전 패치, 켜진 클라 끄기, 버전 확인 |
| 사냥 기록 | 기록 시작 ~ 끝 동안 클라별 전투 횟수, 전투/비전투 시간, 획득 아이템 목록. 지난 기록 보기 |
| 알림 | 거상 홈페이지 새 이벤트 / 마감 전날 알림, 이벤트 페이지를 그 클라 계정으로 로그인된 창으로 열기. 사통팔달에 정한 단어가 나오면 알림 |

## 설치

1. [Releases](../../releases/latest) 에서 `GeoJipsa-버전-win64.zip` 을 받아 원하는 폴더에 풉니다.
2. **Npcap** 을 설치합니다 (상태 판정, 사냥 기록, 사통팔달에 필요 - 처음 한 번).
   - [npcap.com](https://npcap.com/#download) 에서 **Npcap 설치 프로그램** 을 받습니다 (SDK / 소스는 필요 없음).
   - 설치 옵션에서 **"Install Npcap in WinPcap API-compatible Mode"** 를 켜고, **"Restrict Npcap driver's access to Administrators only"** 는 끕니다.
   - Npcap 은 무료판 라이선스상 이 프로그램에 같이 넣어 드릴 수 없어 직접 설치해야 합니다.
3. `GeoJipsa.exe` 를 실행합니다.
   - 관리자 권한을 묻습니다. 거상이 관리자 권한으로 돌기 때문에, 창을 앞으로 가져오기 / 단축키 / 클라 실행에 필요합니다.
   - "Windows의 PC 보호" (SmartScreen) 창이 뜨면 **추가 정보 -> 실행** 을 누르세요 (코드 서명 인증서가 없어서 뜹니다).

Npcap 이 없어도 클라 실행 / 앞으로 가져오기 / 단축키 / 홈페이지 이벤트는 됩니다.
이때 상태는 게임 화면이 1024x768 일 때만 화면으로 대신 판단하고, 획득 아이템과 사통팔달은 받을 수 없습니다.

## 쓰는 법

- **클라 실행**: '클라 실행' 탭에서 클라마다 '설정' -> 설치 폴더 (예: `C:\AKInteractive\Gersang2`), 아이디, 비밀번호, (있으면) 부 계정.
  '열기' 를 누르면 Microsoft Edge 를 화면 없이 띄워 홈페이지에 로그인한 뒤 그 폴더의 게임을 켭니다.
  공식 게임 스타터나 다른 실행기가 떠 있으면 닫아 주세요 (같은 포트를 씁니다).
- **단축키**: '설정' 탭에서 '1클 앞으로' 등에 키를 정합니다. 거상 창이 맨 앞일 때는 그 키가 게임에도 들어가니 게임에서 안 쓰는 키로 고르세요.
- **사냥 기록**: '기록 시작' 을 누르고 사냥한 뒤 '기록 끝'. 기록 중에 앱이 꺼져도 마지막으로 저장된 데까지 남습니다.
- **사통팔달 알림**: '알림' 탭에 단어를 쉼표로 넣습니다 (예: `봉서, 낙수셋`).

## 육의전 공유 시세

처음 켤 때 공유할지 묻습니다. 공유하면 내 클라가 육의전 구매 창을 열거나 검색할 때 받은 목록 (아이템, 수량, 1개당 가격, 판매자 이름,
등록 번호, 서버) 을 익명으로 보내고, 대신 거집사 사용자들이 모은 **서버 전체 시세** (지금 최저가, 7일 중앙값/평균, 판매 목록) 를 '육의전' 탭에서 봅니다.

- 계정 / 아이디 / 캐릭터 이름은 보내지 않습니다. 사용자는 무작위 '설치 번호' 로만 구분합니다.
- 서버는 거상에 로그인할 때 저절로 알아냅니다 (앱을 켜기 전에 이미 접속해 있었다면 '설정' 탭에서 고르세요).
- 언제든 '설정' 탭에서 끌 수 있습니다. 보낸 기록을 지우고 싶으면 설정 탭의 설치 번호와 함께 [Issues](../../issues) 에 요청해 주세요.
- 자동으로 육의전을 넘기거나 게임에 요청을 보내지 않습니다. 사람이 게임에서 본 목록만 모입니다.

## 저장되는 곳

- 설정 / 계정: `%APPDATA%\GeoJipsa\`
  - 비밀번호는 Windows 암호화 (DPAPI) 로 저장해, 이 PC 의 이 Windows 사용자만 풀 수 있습니다. 다른 PC 로 옮기면 다시 입력해야 합니다.
- 사냥 기록 / 사통팔달 기록 / 로그: `%LOCALAPPDATA%\GeoJipsa\`
- 비밀번호는 로그나 화면에 남기지 않습니다 (아이디도 앞 두 글자만 보입니다).

## 지우기

압축을 푼 폴더와 위 두 폴더를 지우면 됩니다. Npcap 은 Windows '앱 및 기능' 에서 지웁니다.

## 알아 둘 점

- 비공식 프로그램입니다. 게임사와 관계가 없고, **사용에 따른 책임은 사용자에게 있습니다.**
- 게임 업데이트로 통신이나 데이터 형식이 바뀌면 일부 기능이 잠시 동작하지 않을 수 있습니다.
- 문제나 건의는 [Issues](../../issues) 에 남겨 주세요. 로그 파일 (`%LOCALAPPDATA%\GeoJipsa\app.log`) 을 붙여 주시면 빨리 볼 수 있습니다
  (로그에 비밀번호는 없습니다).
